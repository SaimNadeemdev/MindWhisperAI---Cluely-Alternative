## <img src="https://img.shields.io/badge/-QUICK_START-ff6b6b?style=flat-square&logo=lightning&logoColor=white" alt="Start"/> Getting Started

### Prerequisites

```bash
# Required
- Node.js 18+ installed
- Git installed
- Either: Gemini API key OR Ollama (for local AI)
```

### Quick Installation

```bash
# Clone the repository
git clone https://github.com/SaimNadeemdev/MindWhisperAI-Cluely-Free-Alternative.git
cd MindWhisperAI-Cluely-Free-Alternative

# Install dependencies
npm install

# Set up environment (see Configuration below)
# Start the app
npm start
```

### Configuration

Create a `.env` file in the root directory:

**For Cloud AI (Gemini):**
```env
GEMINI_API_KEY=your_api_key_here
```

**For Local AI (Ollama - Privacy Mode):**
```env
USE_OLLAMA=true
OLLAMA_MODEL=llama3.2
OLLAMA_URL=http://localhost:11434
```
